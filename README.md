# 🚀 Featured Projects

## 🕵️ FraudHunt

### Multimodal Smart Detection of Fake Online Marketplaces

A multimodal fraud detection system designed to identify **fake review campaigns and marketplace manipulation**.

**490K+ Amazon reviews and products** were processed using a combination of:

* 🧠 NLP
* 👁️ Computer Vision
* ⏱️ Temporal Analysis
* 🕸️ Graph-based Learning
* 🔍 Explainable AI

The system combines **DeBERTa-v3, EfficientNet, and XGBoost** to identify fraud patterns, uncover potential fraud rings, recover authentic product ratings, and generate interpretable fraud-risk scores.

`Python` `FastAPI` `DeBERTa-v3` `EfficientNet` `XGBoost` `NLP` `Computer Vision`
